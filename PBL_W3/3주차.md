# 🟦 Today I Learned - 3주차 PBL

### 1. 오늘 배운 내용
- 자바의 상속(Inheritance)과 추상 클래스(Abstract Class) 활용법
- 인터페이스(Interface)를 이용한 정책 분리 설계
- 다형성(Polymorphism)을 활용해 조건문(if-else) 없이 로직 구현하기에 대해 배웠습니다.

### 2. 핵심 정리 (내 언어로)
- 추상 클래스 : 직접 객체를 만들 순 없지만, 자식들의 공통점을 모아둔 미완성 설계도입니다. '반드시 구현해야 할 기능'을 강제할 때 사용합니다.
- 다형성 : 하나의 타입(부모)으로 여러 가지 객체(자식)를 다루는 기술입니다. 덕분에 코드가 유연해지고 지저분한 조건문이 사라집니다.
- 인터페이스 : 인터페이스 덕분에 객체 간의 결합도를 낮추고 각자의 역할에만 집중할 수 있게 되었습니다.

### 4. 느낀 점
- 처음 추상 클래스를 만들 때 메서드에 {}을 붙여서 에러가 났었는데, "추상 메서드는 선언만 하고 구현은 자식에게 맡긴다"는 개념을 오류 해결 과정을 통해 확실히 알게 되었습니다.
- 이렇게 직접 오류를 마주하며 고쳐나갈 때 가장 많이 배우는 것 같습니다.
- 지난주 실습 때는 조건문으로 역할을 구분했었는데, 이번 주에 다형성을 적용해 보니 코드가 얼마나 깔끔해질 수 있는지 체감했습니다.
- 단순히 기능이 돌아가게 만드는 것이 아니라 확장 가능한 구조를 설계하는 방법에 대해 알게 되었습니다.
- 앞으로 Java 실습을 할 때 습관적으로 조건문을 쓰기보다, 이걸 인터페이스나 추상 클래스로 풀어낼 수 있는지를 고민하는 습관을 들여야겠다고 생각했습니다.
- 깃허브 관리 방식도 주차별로 폴더를 나누니 한눈에 성장이 보이는 것 같아서 뿌듯합니다.
