# 7주차 PBL - Spring Boot 레이어드 아키텍처 구현

## 1. 이번 주차에 배운 점 (TIL)
- **레이어드 아키텍처(Layered Architecture)**: Controller, Service, Repository로 역할을 명확히 분리함으로써 코드의 가독성과 유지보수성이 얼마나 향상되는지 직접 체감했습니다.
- **DTO(Data Transfer Object)의 중요성**: 비즈니스 내부 엔티티(Entity)를 클라이언트에 그대로 노출하지 않고, API 스펙에 맞춘 독립적인 데이터 바구니를 왜 사용해야 하는지 이해했습니다.
- **자바 리플렉션(Reflection) 활용**: 6주차 메모리 저장소 원본의 캡슐화(`private`) 제약 조건을 깨지 않고, 서비스 계층에서 안전하게 데이터를 우회하여 삭제(`removeIf`)하는 고급 메커니즘을 경험했습니다.

## 2. API 테스트 결과 (인텔리제이 내장 HTTP Client)
- 한글 URL 인코딩 이슈(`%EB%B0%95%EB%AF%BC%EC%88%98`)와 오타로 인한 400 Bad Request, 404 Not Found 예외를 디버깅하며 URL 경로 매핑의 정밀함을 배웠습니다.
- 최종적으로 7가지 시나리오(등록, 중복 예외 처리 409, 조회 200/404, 수정 200, 삭제 204) 모두 초록 불을 띄우며 정상 작동함을 검증했습니다.
