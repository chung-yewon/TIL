# 📘 Today I Learned

### 1. 오늘 배운 내용
객체지향 프로그래밍(OOP)의 기초: 클래스 설계, 객체의 생성, 필드와 메서드의 역할 이해에 대해 배웠습니다.
캡슐화(Encapsulation): 외부로부터 데이터를 보호하고, 객체가 스스로 자신의 상태를 관리하게 만드는 방법 학습했습니다.
접근 제어자(Access Modifier): public, default, private의 차이와 패키지/클래스 간 접근 범위 체감할 수 있었습니다.
예외 처리: 자바 Scanner 사용 시 데이터 타입 불일치로 발생하는 InputMismatchException 해결 방법에 대해 배웠습니다.

### 2. 핵심 정리 (내 언어로)
Step 1(main에서 검증)과 Step 2(객체 내 검증)를 비교하며, 데이터를 가진 객체가 스스로 유효성을 검사하는 것이 훨씬 객체지향적이라는 것을 깨달았습니다.
필드에 직접 접근하지 못하게 private이나 default로 제한함으로써, 의도치 않은 데이터 수정을 막고 프로그램의 안정성을 높일 수 있다는 걸 알게 되었습니다.
서로 다른 패키지에 있을 때 default 접근 제어자가 작동하지 않는 것을 보며 패키지 설계의 중요성을 이해했습니다.

### 4. 느낀 점
처음에는 인텔리제이에서 패키지를 나누고 파일을 배치하는 게 낯설었지만, 직접 구조를 잡아보니 자바 프로젝트가 어떻게 구성되는지 감을 잡을 수 있었습니다.
기수를 입력할 때 숫자 뒤에 '기'를 붙였다가 InputMismatchException 에러를 만났는데, 컴퓨터는 정해진 규칙(데이터 타입)을 정말 엄격하게 지킨다는 것을 새삼 느낄 수 있었습니다.
또한 Step 3에서 빨간 줄이 뜨는 것이 실패가 아니라, 자바의 보안 규칙이 제대로 작동하고 있다는 점이 흥미로웠습니다.
