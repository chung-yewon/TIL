# 📘 Today I Learned - 4주차 PBL

### 1. 오늘 배운 내용
- 자바 컬렉션 프레임워크(Collection Framework) 활용법 (List, Map)
- List를 활용한 객체 데이터 관리 및 중복 체크 로직 구현
- Map<String, List<Role>> 구조를 이용한 파트별 멤버 필터링 기능 추가
- 패키지 분리를 통한 프로젝트 구조화 및 제약 사항 준수

### 2. 핵심 정리 (내 언어로)
- List = 모든 멤버를 가입 순서대로 저장하고 관리하는 가변적인 데이터 주머니입니다.
- Map = 파트 이름을 '키'로 사용하여 원하는 그룹의 멤버들만 즉시 뽑아낼 수 있는 구조입니다.
- 다형성 = 부모 타입인 `Role`을 통해 `Lion`과 `Staff`를 한 번에 다루어 코드 효율을 높였습니다.
